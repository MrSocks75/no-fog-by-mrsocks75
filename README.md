# No Fog

**No Fog** is a lightweight Minecraft mod designed to eliminate distance fog and improve visibility across all dimensions.

## Features

* **Crystal Clear Vision:** Removes standard distance fog to maximize your render distance.
* **Universal Dimension Support:** Operates effectively in the Overworld, the Nether, and the End.
* **Client-Side Execution:** Runs entirely on the client, allowing you to use it on multiplayer servers without server-side installation.

## Installation

1. Install a compatible mod loader (Fabrice) on your system.
2. Download the latest `.jar` file from the releases page.
3. Place the file into your Minecraft `mods` directory.
4. Launch the game.
